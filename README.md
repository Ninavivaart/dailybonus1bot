# 🎁 Daily Bonus Bot

Claim your daily bonus and build your streak! Get free rewards every day.

## Features
- 🎯 Daily rewards
- 🔥 Streak bonuses
- 📊 Track your progress
- 🏆 Exclusive prizes
- 💾 Auto-save data

## Commands
- `/start` - Welcome menu
- `/claim` - Claim your daily bonus
- `/status` - Check your streak
- `/help` - Need assistance?

## Deploy on Railway
1. Fork this repo
2. Create Railway project
3. Add `BOT_TOKEN` environment variable
4. Deploy!
